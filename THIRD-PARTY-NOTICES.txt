Private launcher source review - 2026-10-09

This repository contains launcher application source and synthetic tests only.
It contains no game assets, game executable, game-engine source, compatibility
runtime binaries or source, game binary-patch data, user saves, private signing
keys, recordings, or compiled launcher package. Paths and SHA-256 fingerprints
of supported user-supplied files are validation metadata, not game content.
