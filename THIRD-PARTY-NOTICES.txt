UWP Spider Launcher - third-party notices

The source repository contains launcher/converter source, numeric recipes,
notices and necessary build materials. It contains no game executable/assets,
game shader bytecode, generated shader recipes, caches, private runtime binaries,
user saves or signing keys. Optional tests and internal review tools are separate.
These source exclusions do not approve arbitrary externally supplied combined
runtime binaries or the private 0.6.0.39 installer, which contained embedded game
shaders. No public combined installer is supplied by this source candidate.
