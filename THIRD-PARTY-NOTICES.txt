UWP Spider Launcher - third-party notices

The source repository contains launcher/converter source, numeric recipes,
notices and build tools. Optional test suites are maintained separately. The 0.6.x private test package
contains the compiled launcher, its converter helper, recipes and notices.
Neither includes game assets, game executable, game-engine source, compatibility
runtime binaries or source, game binary-patch data, user saves or signing keys.
The separate runtime supplies its private preparation support. This separation
does not establish permission to redistribute that runtime.

Launcher Steam transfer implementation (2026-10-10)
The downloader in source/SteamTransfer, SteamDownload.cs, SteamChecks.cs and
SteamProbe.cs is a new implementation using the public SteamKit API directly.
It is not an adaptation of DepotDownloader. These new files are licensed
GPL-3.0-or-later; full text: licenses/Launcher-GPL-3.0.txt.
DepotDownloader sources and compiled components are absent from this candidate.
Earlier private revisions used DepotDownloader and retain their own notices
in repository history. This statement does not relicense those earlier files.
