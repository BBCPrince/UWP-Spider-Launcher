# License and distribution status

The current launcher downloads through an independent SteamKit implementation. DepotDownloader is not part of this revision; older revisions preserve their own source and notices.

The new transfer implementation is GPL-3.0-or-later. The adapted asset converter is GPL-3.0-only. Third-party components keep their own licenses and attribution; see [notices](THIRD-PARTY-NOTICES.txt) and [dependency inventory](DEPENDENCIES.json).

Public binary distribution remains pending:

- A complete matching source/build distribution for the exact binaries shipped, including the native-linked SteamKit arrangement.
- Review of the exact framework and helper redistribution requirements.
- Independent provenance and redistribution review of any separate runtime, which is not included here.
- Completion of the release validation recorded in [release status](release/STATUS.md).

The existing build and package checks do not grant runtime redistribution rights or establish compliance with game/platform terms. The public-release guard remains enabled.
